Viewer

Open an image. If it carries Image Scale Metadata, the scale is read from the file itself and drawn on the picture — no software from the maker needed. If it has a ruler in the picture but no scale, measure the ruler once and download the picture with its scale written in. Nothing is uploaded: the file is read and written in your browser.
